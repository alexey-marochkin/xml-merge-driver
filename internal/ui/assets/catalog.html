НАСТРОЙКА СООТВЕТСТВИЯ

Новое правило

Правило действует на любой глубине. Например: Item, xr:GeneratedType или {urn:example}Item. Звездочка * задает настройку по умолчанию.

Поля составного ключа

Используется собственное текстовое значение без текста потомков.

Без собственного правила действует общая настройка «Все элементы».

Удалить правило?

Элемент будет использовать общую настройку «Все элементы». Удаление будет записано на диск при сохранении файла.

Сохранить изменения?

В файле правил есть несохранённые изменения.
